# Open-Source Icon Fonts

This directory contains open-source and freely redistributable icon fonts used by Waybar and Rofi:

- **IcomoonFeather.ttf**: Feather Icons by Cole Bemis (MIT License).
- **MaterialSymbolsRounded.ttf**: Material Symbols by Google (Apache License 2.0).
- **SymbolsNF.ttf**: Nerd Font glyph symbols by Ryan L McIntyre (MIT / SIL Open Font License).

These fonts are installed by `install.sh` into `~/.local/share/fonts/wm/`.
